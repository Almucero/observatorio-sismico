# Frontend del observatorio

Base Angular 20 + Leaflet del material del curso. Modo `demo` (cuatro eventos ficticios) o `api` (`public/config.json`).

```bash
npm ci
npm start
```

Abrir http://localhost:4200

Pendiente de ampliar según `docs/requisitos/ENUNCIADO.md` §8: filtros, tabla, gráficos, `last_ingestion`, truncado, REPRODUCCIÓN.

Publicación: ver `docs/requisitos/README-MATERIAL-BASE.md` y `netlify.toml`.
